# Support

This project audits OpenClaw installations. It does not operate, repair, or provide emergency support for a running OpenClaw Gateway.

Use the repository issue forms for:

- reproducible scanner or renderer defects;
- incorrect drift classification;
- missing support for an installation or package layout;
- feature proposals for a future audit capability.

Before filing an issue:

1. remove all secrets, identities, private paths, logs, memories, transcripts, and raw configuration values;
2. include the OpenClaw and component versions, installation kind, operating system, capability status, and relevant Coverage Gaps;
3. reproduce with a minimal synthetic fixture when possible.

For OpenClaw product support, consult the [official OpenClaw documentation](https://docs.openclaw.ai). For a security vulnerability in this project, use [SECURITY.md](SECURITY.md).
