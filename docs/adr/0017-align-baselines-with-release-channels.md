# Align baselines and upgrades with release channels

The auditor detects each component's Release Channel and never applies prerelease or main-branch recommendations to a stable Operational Baseline. Stable installations receive stable upgrades; intentional beta or release-candidate installations receive a Channel-Aligned Upgrade Contract plus the current stable return path. Nightly and unreleased main changes remain Candidate Evidence, while security fixes in another channel are availability notices rather than silent upgrade requirements. Cross-channel OpenClaw and plugin combinations are assessed explicitly for compatibility.
