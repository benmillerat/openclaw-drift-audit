# Condition recommendations on operating context

Every recommendation is evaluated against an Operating Context Profile covering tenancy, exposure, sender trust, workload, latency-quality-cost-privacy priorities, hardware, local services, and security posture. The auditor infers only evidence-supported facts and asks for missing facts when they materially alter a result; otherwise it emits multiple Conditional Recommendations or a Coverage Gap rather than selecting a universal posture. This adds user context to the audit but prevents personal-workstation defaults from being applied to shared or exposed installations and vice versa.
