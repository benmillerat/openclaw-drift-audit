# Evaluate distinct effective scope combinations

Recommendations and drift are evaluated for every distinct Effective Scope across agents, channels, accounts, conversation boundaries, workspaces, plugin and tool policies, sessions, and automations rather than only against root configuration. Equal outcomes form a Scope Equivalence Class for compact reporting, while inherited differences and State Overlays expand into specific findings. This adds resolution work but exposes Inheritance Drift such as a globally valid group list becoming ineffective for another bot account.
